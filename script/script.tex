	\section{【剧本正文】}
	
	\subsection{开场}
	
	\textbf{画面/音效：}
	屏幕上出现一只巨大的鲨鱼，张开充满血腥感的嘴巴，露出尖锐的牙齿。背景中播放凄厉的惨叫声。
	
	\textbf{灯光：}
	舞台灯光突然闪烁，随后迅速变暗。鲨鱼的嘴巴占据整个屏幕，仿佛正在吞噬一切。
	
	\textbf{音效：}
	惨叫声突然停止，画面瞬间切黑。
	
	\vspace{1em}
	
	\subsection{第1幕：会议}
	
	\subsubsection{场景信息}
	
	\textbf{场景：} 会议室
	
	\textbf{时间：} 白天
	
	\textbf{人物：} 校长、开明老师、群众领导、群众老师
	
	\subsubsection{剧情内容}
	
	\textbf{场景布置：}
	校长站在讲台上给老师和领导们开会。所有人坐在椅子上，表情严肃，双手整齐地放在桌面上。
	
	\textbf{动作/灯光：}
	会议开始前，全场人员的身体统一向舞台右侧倾斜约四十五度，头部却保持正对校长，脸上没有任何表情。
	
	\textbf{校长：}
	最近教育部要求提高学生综合素养，不要只会死读书，大家赞不赞同？
	
	\textbf{动作/音效：}
	音乐响起。全场人员的身体统一向舞台左侧倾斜约四十五度，同时转头看向校长。随后，所有人整齐地拍手三下。第三下结束时，音乐戛然而止，全场瞬间静止。
	
	\textbf{全场：} （异口同声）赞同！
	
	\textbf{校长：}
	为了全面提高学生的综合素养，星期六改为课外兴趣培训班，好不好？
	
	\textbf{动作/音效：}
	音乐再次响起。全场人员的身体统一向舞台右侧倾斜约四十五度，身体统一向另一侧摆动，随后整齐地拍手三下。第三下结束时，所有人瞬间恢复原来的倾斜姿势，纹丝不动。
	
	\textbf{全场：} （异口同声）好！
	
	\textbf{老师：}
	（试图坐直，身体却与周围人的倾斜姿势形成鲜明对比）这样会占用学生的课余时间。
	
	\textbf{动作：}
	音乐突然停止。所有人同时僵住，缓缓将头转向开明老师，只有眼睛保持直视前方。老师环顾四周，发现没有人敢与自己对视。
	
	\textbf{校长：}
	好不好笑？
	
	\textbf{动作/音效：}
	全场整齐的笑声：“哈哈哈！”笑声节奏统一，身体随着每一声笑向同一侧摆动。笑声结束，所有人同时收住表情，恢复僵硬的倾斜姿势。
	
	\textbf{开明老师：}
	（欲言又止，慢慢低下头）
	
	\textbf{校长：}
	散会。
	
	\textbf{动作/音效：}
	音乐再次响起。迈着僵硬的步伐离开会场。灯光渐暗。

	\subsection{第2幕：周六兴趣班}
	
	\subsubsection{场景信息}
	
	\textbf{场景：} 教室
	
	\textbf{时间：} 星期六，白天
	
	\textbf{人物：} 老师、群众学生
	
	\subsubsection{剧情内容}
	
	\textbf{场景布置：}
	教室顶上的电子钟显示：星期六。黑板上写着：
	
	\begin{center}
		\Large 电路设计兴趣小组
	\end{center}
	
	所有学生坐在桌子前。每张桌子上摆放着一块电路板，讲台上放着一个电子报时器。学生们面无表情，双手整齐地放在桌面上，视线统一朝向讲台。
	
	\textbf{动作/音效：}
	突然，报时器发出一声清脆的“滴”。所有学生同时低下头，以一致的动作给电路通电。电路开始工作，亮起一盏小黄灯。
	
	\textbf{老师：}
	大家有没有感觉到自己的素质提高了？
	
	\textbf{所有学生：}
	（异口同声）有。
	
	\textbf{动作/音效：}
	报时器再次发出一声“滴”。所有学生马上站起来，迈着机器人一样的步伐，和老师一起离开教室。
	
	\textbf{动作：}
	所有人离开后，黑板上的字自动改为：
	
	\begin{center}
		\Large 兴趣小组结束
	\end{center}
	
	\textbf{画面/音效：}
	相机快门声响起。画面定格在空无一人的教室、整齐排列的电路板和仍然亮着的小黄灯上。
	
	\textbf{音效：}
	激昂的音乐。（比如进行曲）
	
	\textbf{衔接动作：}
	学生们迈着整齐的步伐走出教室，穿过走廊，迎面遇到了正在巡视的教育部部长一行人。

	\subsection{第3幕：领导视察}
	
	\subsubsection{场景信息}
	
	\textbf{场景：} 学校走廊 / 校园内
	
	\textbf{时间：} 白天
	
	\textbf{人物：} 教育部部长、校长、秘书、学生A
	
	\subsubsection{剧情内容}
	
	\textbf{场景布置：}
	校园走廊外，阳光明亮。树木在地面投下大片阴影，形成明显的明暗交界线。部长站在阴影区域，校长与秘书站在部长身旁。远处，学生沿着预先安排好的路线走来。
	
	\textbf{灯光/动作：}
	部长迎面拦住学生A。学生A原本站在阳光照射的区域。部长开始提问时，从阳光下进入树荫。
	
	\textbf{动作：}
	部长正准备开口，学生A突然向前一步，声音洪亮地抢先回答。
	
	\textbf{学生A：}
	这个活动非常有意义，不仅提高了我们的综合素质水平，而且开拓了视野，真是令学生受益匪浅！
	
	\textbf{动作：}
	全场瞬间安静。部长脸上的笑容凝固，缓缓转头看向学生A。
	
	\textbf{教育部部长：}
	等等。为什么我还没问你，你就回答了？
	
	\textbf{学生A：}
	这显得您问得准呀！
	
	\textbf{动作/音效：}
	全场沉默三秒。学生A依然面带微笑，一动不动。校长先是愣了一下，随即立即鼓掌三下。
	
	\textbf{教育部部长：}
	（愣了一下，随即露出满意的笑容）好！有觉悟！有水平！
	
	\textbf{动作：}
	部长拍了拍学生A的肩膀。学生A保持微笑，
	
	\textbf{教育部部长：}
	加把劲，继续努力！
	
	秘书拿出相机，准备拍摄。
	
	\textbf{画面/音效：}
	相机快门声响起。画面定格。
	
	\textbf{动作/音效：}
	一阵清脆激昂的放学铃声响起。刚才还保持僵硬定格的学生们瞬间解冻，欢呼着蜂拥跑向校门方向。

	\subsection{第4幕：蜕变与轮回}
	
	\subsubsection{场景信息}
	
	\textbf{场景：} 校门外 / 校园大树
	
	\textbf{时间：} 白天
	
	\textbf{人物：} 群众学生
	
	\subsubsection{剧情内容}
	
	\textbf{动作/画面：}
	学生们走向校门的过程中，肢体动作逐渐变得敏捷而怪异。在移动中，他们慢慢变成了穿着原来学生衣服的猴子。
	
	\textbf{动作：}
	这群穿着校服的猴子纷纷兴奋地爬到校门口的一棵大树上欢快地玩耍、打闹。
	
	\textbf{合唱：}
	（猴子们在树上异口同声地高声合唱，反复多次）
	我们是莎士比亚的猴子！
	我们是莎士比亚的猴子！
	我们是莎士比亚的猴子！
	
	\textbf{动作/音效：}
	突然，一阵急促而严厉的上课铃声响起。猴子们瞬间停止玩耍，纷纷迅速从树上爬下来，再次面向校门走去，准备走进校门。
	
	\textbf{动作/画面：}
	在走回校门的过程中，他们的身体再次发生变化，逐渐恢复变成了学生的样子。
